## 🚀 Local Deployment Sequence

Follow the steps below to initialize the system locally.

1️⃣ Clone the Repository

git clone https://github.com/Ambujkumar909/ambuj-portfolio.git
cd ambuj-portfolio

2️⃣ Install Dependencies
npm install

3️⃣ Activate Development Server
npm run dev


The application will be available at:

http://localhost:5173

📂 Project Architecture

This project follows a Flat Root Structure for:

  Faster builds
  Cleaner ESM imports
  Reduced cognitive overhead
  
ambuj-portfolio/
├── App.tsx             # Core Logic & UI Composition
├── constants.tsx       # Data Matrix (Projects, Skills, Automations)
├── types.ts            # TypeScript Interface Definitions
├── index.tsx           # React DOM Entry Point
├── index.html          # Cinematic Shell
├── vite.config.ts      # Optimized Build Pipeline
└── package.json        # Dependency Manifest
